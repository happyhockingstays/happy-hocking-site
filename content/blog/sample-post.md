## A section heading

Short paragraphs read best. Lead with the feeling, then prove it with a fact. Link the cabin name to its page the first time it comes up, like [Clouds Reach](/cabins/clouds-reach).

- Lists work for quick picks
- Keep each line short
- 3 to 5 items is plenty

### A smaller heading

Add a photo by picking it from the media library. The description you type becomes its alt text.
